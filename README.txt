YAN TRAINER v0.8

이번 버전 핵심 변경
- 우클릭 이동은 v0.3에서 동작하던 방식으로 재구성.
- A + 좌클릭은 클릭한 지점으로 이동하지 않고, 마우스 위치 기준 가장 가까운 더미를 대상으로 공격.
- 기본 스킬 쿨다운의 원본값은 Q 8초 / W 15초 / E 8초.
- 상시 아이템 쿨감 30%를 먼저 적용하므로 실제 훈련장 쿨다운은 Q 5.6초 / W 10.5초 / E 5.6초.
- 강화 스킬은 각 스킬의 '전체 유효 쿨다운'의 30%를 고정 차감.
- 강화 E는 위 30% 차감 후 E의 '전체 유효 쿨다운'의 40%를 추가 차감.
- R은 쿨다운 0초이며 사용 즉시 패시브 5스택.
- 패시브 최대 10스택.
- 5스택 이상이면 다음 Q/W/E가 강화.

Q
- Q1 → Q2 2단계.
- Q1 사용 후 3초 동안 Q2 가능.
- 3초 안에 Q2 사용: 즉시 Q 쿨다운 시작.
- 3초 동안 Q2를 사용하지 않음: 자동으로 Q 쿨다운 시작.
- Q 기본 원본 쿨다운 8초 → 상시 30% CDR 적용 후 5.6초.

W
- 0.45초 시전 대기 후 90도 부채꼴 판정.
- W 기본 원본 쿨다운 15초 → 상시 30% CDR 적용 후 10.5초.

E
- 커서 방향으로 고정거리 돌진.
- E 기본 원본 쿨다운 8초 → 상시 30% CDR 적용 후 5.6초.
- 강화 시 공통 30% + E 추가 40% 차감.

R
- 현재 적중 판정 없음.
- 쿨다운 0.
- 사용 즉시 +5 스택.

실제 라이브 게임의 모든 피해량/애니메이션/예외적인 패시브 조건은 아직 미구현.

v0.9 변경
- Q/W/E/R 스킬 HUD를 다시 항상 표시되도록 고정.
- HUD에 z-index/visibility/opacity 보호 추가.
- 각 프레임마다 스킬 박스의 표시 상태를 명시적으로 복구.
- 공격 간격을 기존 0.38초의 0.75배인 0.285초로 변경.
